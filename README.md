# ceske-kalkulacky

Společný web českých kalkulaček a průvodců (pracovní název **Spočítáno**).

- `docs/zadani.md` – zadání všech aplikací (zdroj pravdy)
- `docs/informacni-architektura.md` – kategorie, navigace, URL, vazby, vyhledávání, názvy webu
- `docs/rozhodnuti.md` – předpoklady a rozhodnutí, výsledky kontrol
- `docs/zadani-faze-2.md` – zadání 2. fáze: sestavení webu ve variantě B ve třech vlnách
- `designs/index.html` – rozcestník čtyř variant designu (otevřete přímo z disku)
- `designs/porovnani.html` – všechny varianty vedle sebe v jednom souboru
- `tools/kontroly/` – kontroly přístupnosti, přetečení a externích požadavků (Puppeteer + axe)
